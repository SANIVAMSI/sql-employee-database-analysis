# SQL Employee Database Analysis

## Project Overview
This project demonstrates practical SQL development and business data analysis using Oracle SQL.

The project uses employee and department datasets to perform data analysis, business reporting, and data validation.

## Technologies Used
- Oracle SQL
- SQL Developer
- Microsoft Excel
- GitHub

## Project Structure
- `01_Database_Scripts` – Database table creation scripts
- `02_Sample_Data` – Sample datasets
- `03_SQL_Queries` – SQL business analysis queries
- `04_Query_Results` – Exported query results
- `05_Test_Cases` – SQL test cases and validation results
- `06_Documentation` – Project documentation

## Key SQL Concepts
- Joins (INNER, LEFT, RIGHT, FULL)
- Aggregate functions
- GROUP BY and HAVING
- Subqueries
- Analytical functions
- Ranking functions
- Department-wise salary analysis
- Data validation

## Project Deliverables
- SQL scripts
- Query result files
- Excel test case workbook
- Project documentation
